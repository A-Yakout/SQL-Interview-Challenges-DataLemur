# 🐒 SQL-Interview-Challenges-DataLemur

## 📌 About This Repository
This repository is a personal log of my daily SQL problem-solving journey on [DataLemur](https://datalemur.com/). As a Data Analyst with a deeply analytical mindset, I believe in the power of consistency and building strong, compounding habits. 

My goal is to solve at least **one SQL interview challenge every day**. This consistent practice is designed to sharpen my problem-solving skills, bridge the gap between theoretical syntax and real-world business logic, and master advanced SQL concepts.

## 🎯 The Challenge
- **Goal:** Solve a minimum of 1 SQL problem daily.
- **Focus Areas:** Window Functions, CTEs, Advanced Joins, Data Aggregation, and Time-Series Analysis.
- **Platform:** DataLemur (Focusing on FAANG & Tech Interview SQL Questions).

## 💡 Why This Challenge?
DataLemur provides excellent exposure to messy, real-world datasets and actual interview questions from top tech companies. Documenting my solutions here not only serves as a personal reference guide but also showcases my approach to translating complex business requirements into clean, optimized SQL code.
